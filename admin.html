1 · 授权（只需一次）

怎么拿到这个 Token？（点开看步骤）
  1. 打开 github.com/settings/personal-access-tokens（Settings → Developer settings → Personal access tokens → Fine-grained tokens）
  2. 点 Generate new token
  3. Repository access 选 Only select repositories → 只勾 blog
  4. Permissions → Repository permissions → Contents 设为 Read and write
  5. 生成后复制，粘到上面输入框，点「记住这台电脑」
